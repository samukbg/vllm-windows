## Operational Notes

- **Cache wipe not needed.** 47K cold prefill hit ~5800 tok/s on first try, well in devnen IDEAL zone.
- **No OOM at any size**, including 256K cold with gpu-mem=0.92.
- **FlashInfer JIT** required `ninja` binary visible on `PATH`; the launch script prepends `.venv/bin` to handle this.
- **vLLM 0.20.2 flag change**: `--disable-log-requests` is gone, use `--no-enable-log-requests`.
- **Model trip-wire**: `Qwen3_5ForConditionalGeneration` auto-detects as VL → needs `--language-model-only` to skip the missing `preprocessor_config.json`.
- **Initial cold boot** ~115 s (model load 2 s + warmup 80 s + torch.compile 41 s + FlashInfer autotune 2 s + CUDA graphs 1 s). Subsequent boots ~50 s with compile cache hot.
